# auto-dist 前端工作台重设计

**日期：** 2026-07-13  
**状态：** 已确认  
**范围：** `packages/client` 样式与布局；功能保持，交互可微调

## 目标

将现有「单卡片 + 强制 Steps」界面，重做成浅色、清晰的本地构建工作台：左侧配置，右侧构建状态与日志。

## 决策摘要

| 项 | 选择 |
|---|---|
| 范围 | 视觉 + 布局，做成完整构建工作台 |
| 调性 | 浅色干净工作台 |
| 布局 | 左侧固定配置栏，右侧主区（构建 + 日志） |
| 功能 | 能力不变；交互可微调（非强制线性步骤、日志固定占满剩余高度） |
| 实现路径 | Ant Design 主题化工作台（ConfigProvider token + 布局重构） |

## 整体布局

全高工作台结构：

```
┌─────────────────────────────────────────────┐
│  顶栏：auto-dist · 副标题 · 状态摘要          │
├──────────────┬──────────────────────────────┤
│  左侧配置栏   │  右侧主工作区                  │
│  (~320px)    │                              │
│              │  ┌ 构建摘要 / 操作按钮 ──────┐ │
│  ① 扫目录     │  │ 开始 / 取消 / 全部下载    │ │
│  ② 选项目     │  └──────────────────────────┘ │
│  ③ 选分支     │  ┌ 项目构建列表 ────────────┐ │
│  ④ 更换项目   │  │ 状态 Tag · 下载 · 开文件夹│ │
│              │  └──────────────────────────┘ │
│              │  ┌ 构建日志（flex 占满剩余）─┐ │
│              │  │ 浅色终端感日志区           │ │
│              │  └──────────────────────────┘ │
└──────────────┴──────────────────────────────┘
```

### 交互规则

- 去掉强制线性 Steps；左侧分区标题代替步骤条。
- 左侧配置在空闲时可随时修改；**构建进行中时禁用左侧变更**。
- 右侧在「尚未选满分支」时显示空状态引导；选满后显示构建区。
- 「更换项目」放在左侧，清空选择并重置构建相关状态。
- 日志固定在主区底部，构建时自动滚动到底部。

## 组件拆分

| 区域 | 组件 / 职责 |
|---|---|
| 壳 | `App.tsx`：顶栏 + 左右分栏，接入 `useBuild` |
| 左侧 | `DirectoryPicker`、项目多选、每项目 `BranchSelector`、更换项目 |
| 右侧上 | `BuildPanel`：摘要、操作按钮、项目状态列表 |
| 右侧下 | `LogViewer`：占满剩余高度的日志区 |

### 不变部分

- `packages/client/src/api`、`useBuild`、Socket 日志逻辑保持不变。
- 仅在布局层增加：构建中禁用配置、空状态、状态摘要展示所需的接线。

## 主题与视觉

通过 Ant Design `ConfigProvider` 调整 token：

- 主色：`#1677ff`（Ant 默认蓝，token 可微调明度）
- 圆角：8px
- 字号/行高略放大，提升可读性
- 面板：白底、细边框（`#e8e8e8`）、无阴影
- 页面底：浅灰 `#f7f8fa`
- 日志区：浅灰底（`#fafafa`）、等宽字体；stdout `#262626`，stderr `#cf1322`，项目名前缀 `#1677ff`

## 状态设计

### 顶栏状态摘要

| 场景 | 文案 |
|---|---|
| 空闲 | 未开始 |
| 构建中 | `构建中 · {current}/{total}` |
| 完成 | `已完成 · 成功 {n} · 失败 {m}` |

### 右侧主态

1. **空状态**：图标 + 引导文案「请在左侧完成项目与分支选择」，无操作按钮。
2. **可构建**：项目/分支摘要 +「开始构建」；可预展示待构建项目列表。
3. **构建中 / 完成**：状态列表（等待 / 构建中 / 完成 / 失败 / 跳过）+ 取消 / 全部下载 / 重新构建 + 实时日志。

### 日志区

- `flex: 1` 占满主区剩余高度，避免整页无限拉长。
- 右上角「清空」；有当前项目时显示「当前构建：{name}」。
- 新日志自动滚到底部。

## 响应式

- 桌面优先：宽度 ≥1100px 左右分栏。
- 较窄屏：上下堆叠（配置在上、主区在下）。
- 不做完整移动端适配。

## 验收标准

- [ ] 可完整走通：扫目录 → 多选项目 → 选分支 → 构建 → 看日志 → 下载
- [ ] 构建进行中无法修改左侧配置
- [ ] 未选满分支时右侧为空状态引导
- [ ] 视觉统一为浅色工作台，不再是单卡片纵向 Steps
- [ ] 日志区固定占满主区剩余高度并自动滚动

## 非目标

- 不更换技术栈（继续 React + Ant Design）
- 不改服务端 API / 构建管线
- 不新增业务功能（如构建历史、权限、多用户）
- 不做完整移动端体验
